两地各有独立的事项编码、来源 ID、官方材料 ID、附件 ID、机构、来源版本及 SHA256 清单。即使官方公开文件的字节一致，也分别保留自身事项中的附件关联与真实下载凭据，没有从邻区复制附件来源。

官方原文办理形式均为“窗口办，网上办，邮寄办”；当前事项关联的网上办理深度为“材料预审（Ⅱ级）”。通用字典中的Ⅲ级、Ⅳ级说明不是该事项的网办能力。实际点击申报进入官方登录界面后停止，未登录或提交申请，也不宣称可在本平台完成正式网上仲裁申请。现场要求和材料份数分别保留原文，不将“份数”当成证据页数或软件容量限制。

`safe-*.json` 是公开接口原文的安全投影，删除了临时文件签名参数；原始采集证据单独保留，不公开动态签名或登录参数。`SOURCE-PROJECTION-MANIFEST.json` 和 `OWN-SOURCE-PINS.json` 固定各文件的长度、SHA256、适用地区、采集时间和官方版本（实际为 `1`）。`guide.json` 的 `published`、`can_generate` 均保持 `false`，未从其他地区继承委员会全称、模板适配或发布审批。

两地自己的申请书和证据清单已完成独立 Word 导出与版式复核：12 份实际导出、48 页，包含原件、正常填写和容量压力样例；空白下载保持原件字节。该文档验收不等于候选网页、最终发布或商业受理保证。后续通过真实网页、接口契约、跨区拒绝、冷启动和部署验收后，才单独增量发布。

平台是劳动仲裁辅助工具，并非官方政务网站。管辖、材料和受理条件以当地仲裁机构实际审查为准。
