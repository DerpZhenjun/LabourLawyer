实际发现并修复的问题是 JSON 模块加载：模拟器报 data/provinces.json.js 未定义，旧首页和新区县页都受影响。增加失败测试后，从原 JSON 自动同步生成三份 CommonJS 数据模块，改四处导入；源 JSON 与业务规则不变。JS-only 模块加载测试和三份数据精确内容比对通过，prebuild 加入同步检查。

初期 SDK 导航、截图及原生弹窗命令曾超时，重复项目会话还出现页面数据和 DOM 不一致；这些状态没有记为通过。正常关闭重复的本项目窗口并单独重开后，使用一致的原生页面与实际桌面确认完成验收。公开截图直接保存已观察像素；原始机器日志和失败细节保留在私有运行目录。开发工具存在文字 selectable 弃用、预加载及测试滚动选择器警告，未将这些警告写成产品功能成功。
