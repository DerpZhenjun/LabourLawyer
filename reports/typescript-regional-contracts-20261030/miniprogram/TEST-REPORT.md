# 区县小程序页面验证

新增独立区县页面，按真实目录选择省、市、区县，再读取本区指南、材料、空白原件和表单合约。省级文书入口保留，另加区县入口说明。

字段、空值、虚构示例、校验和生成请求全部调用共享契约运行时。页面不维护省级字段或容量副本，不默认填写日期、份数、意愿或签名。原文输入不截断；技术容量与官方材料要求分别显示。

验证命令：

```
node miniprogram/tests/regional-page.test.cjs
node scripts/test-document-clients.cjs
```

结果：18 组区县 Page/transport 检查通过；旧省级客户端的 34 份实际请求结构和原页面行为回归通过。新测试先观察到页面缺失的失败，再完成实现；Unicode 字符计数新增测试先观察到 UTF-16 计数差异，再修正为与共享容量相同的码点计数。新增合约响应头缺失及不匹配的失败测试后，生成文件也严格核对 X-Form-Contract-ID。

覆盖地区切换立即清空、请求中止、A→B→A 迟到回调、合约来源与版本绑定、未知及稀疏草稿保留并拒绝生成、旧草稿确认清空、单条证据起步及动态增删、日期/份数/XML 校验、取消确认、重复确认、HTTP 409/422、文件来源/版本/原件 SHA 响应头、不完整 ZIP 拒绝、重复文件回调、迟到保存和预览隔离，以及存储失败时仍可生成。

生成文件检查 ZIP 完整目录、局部条目边界和 Word 必需文件名；此检查不声称解压 XML 或校验 CRC。空白原件支持 DOCX、DOC、PDF 格式识别，响应头必须匹配指南来源、版本和原件 SHA。

本报告中的 Page/transport 测试使用虚构地区、虚构资料、内存网络及设备 IO 模拟；测试本身未连接服务。后续真实微信开发者工具验收另见 ../miniprogram-browser/TEST-REPORT.md，包括实际接口、原生控件、生成文件与截图。真机和发布流程未验收。

真实模拟器发现旧首页和新区县页直接 require JSON 导致模块加载失败。新增 JS-only 模块加载失败测试后，用 scripts/sync-data.cjs 从三份原 JSON 自动生成 CommonJS 模块，四处导入改用 JS 模块。原 JSON 与省级规则未修改。三份数据逐份精确比对通过；npm --prefix miniprogram run build 的 prebuild 自动执行同步检查。

共享运行时由共享契约构建流程提供，清单仅登记本任务拥有的页面、请求封装和测试；未手写或修改生成产物。
