# 湖南两地自身历史DOC与转换副本验收

Reference authority: each district's own public-catalogue.json, attachment-observation.json, originals.json and four original binary DOC files. Blank and sample roles remain separate. The original DOC SHA, download URL, original name, material and approve_id bind each acquisition to its own district. Do not reuse another district's source merely because its bytes match.

Read-only isolated Word exports the original DOC to PDF first. Only the two blank application forms per district are then saved under derived/ as separate DOCX conversion copies. A derived DOCX is a platform conversion, never an official DOCX download. Preserve all original DOCs unchanged. Distinct PID and every document window PID must match; no attachment to or quitting any prior Word instance. Macros disabled and link updates disabled. After own instance exits, bundled Poppler produces images and every page must be inspected before claiming layout QA.

Any future filling must use an inspected slot contract for this exact derived worker or employer form. Signatures remain blank, copy counts are not assumed, source placeholders must not become default case facts, and original mixed time/copy-count statements remain visible in the guide. No models, case database or candidate service are used.

Inspected worker form: one table, 57 rows, one column. Rows 0–8 are the named applicant/respondent/representative/contact/third-party fields. Row 10 is the request label, rows 11–18 its fill slots. Row 19 is the facts label, rows 20–32 its fill slots. Row 33 holds destination, blank signature, date, copy count and all four instructions. Row 34 labels embedded evidence/source/witness description; rows 35–56 are its fill slots. Fill only these own slots. Remove only unused blank request, fact and embedded-evidence rows; keep original labels, notes, fonts and page/table geometry. Do not invent an independent evidence-list document. Let fields wrap naturally within source rows. A first revision forced manual line breaks in six header fields, adding a largely empty third page; it is retained under attempts/first-layout. The accepted revision preserves the source's single-line flow and natural wrapping, yielding two pages per fictional worker application without shrinking fonts. Only word/document.xml changes relative to each own derived DOCX package.
