# 数字人使用与排查

## 启动与打开

双击根目录 `start.bat`，首页 **1 WEB** 启动网页，**2 DESKTOP** 启动 Windows 桌面端。这两个入口会同时启动 API（8000）、网页（5173）和数字人（3000）。也可用 **CLIENTS → DIGITAL HUMAN** 或 `start.bat digital-human` 单独补启动所需服务。

网页点击“AI 法律顾问”，再点击“数字人”。独立页面地址是 `http://127.0.0.1:3000/`。关闭咨询窗口不会停止服务；停止用 **首页 3 STOP** 或 `start.bat stop`。小程序启动入口只需要网页/API，不启动数字人。

## 对话与语音

- 数字人问答经自己的 `/api/chat/` 转发到项目 `/api/ask`，与网页使用同一后端模型，不再固定请求旧的 `qwen3:1.7b`。当前统一使用 Ubuntu `10.66.66.1:11434` 上的 `qwen3.8:27b`；无需启动 Windows 本机 Ollama。
- 输入问题后按 Enter 或点击“发送问题”；Shift + Enter 换行。回答实时显示，历史记录仅存于当前浏览器。
- “语音”按钮在支持语音识别的浏览器中请求麦克风权限；识别失败仍可输入文字。识别能力和联网要求取决于浏览器。
- 右上角“朗读关/开”控制语音，默认关闭。没有配置 GPT-SoVITS 时采用浏览器中文语音，是否有中文声音取决于系统和浏览器；浏览器朗读不驱动 VRM 口型。
- 可以在形象区域旋转视角，点击 ↺ 重置；拖入本地 `.vrm` 文件可以替换当前形象。

## 可选 GPT-SoVITS

项目不会默认启动或下载 GPT-SoVITS。若已有可用服务，在启动数字人前设置进程环境变量：

```powershell
$env:LABOURLAWYER_TTS_URL = 'http://127.0.0.1:9880/tts'
$env:LABOURLAWYER_TTS_REF_AUDIO = 'D:\your-voice\reference.wav'
$env:LABOURLAWYER_TTS_PROMPT = '参考音频中实际说出的文字'
.\start.bat digital-human
```

参考音频须为你实际准备的文件，参数需与所用 GPT-SoVITS 接口一致。配置在服务器读取，通过 `/api/tts/` 请求；不把电脑文件路径固定写进浏览器代码。服务失败时回退到浏览器朗读。改变这些环境变量后，需要重新启动数字人进程；仅重新打开窗口不会改变已运行进程的配置。

## 连接失败

- 窗口先检查数字人健康接口；连接失败显示解释、独立页面链接和“重新连接”，不会展示浏览器灰色拒绝连接页。
- 3000 服务启动、8000 后端可用和本地模型能回答是三个不同条件。角色能显示但“问答未连接”时，检查 `http://127.0.0.1:8000/health`、Ollama 和 `.runtime/backend-error.log`。
- 角色加载失败时仍可文字咨询。核对 `ChatVRM/public/AvatarSample_B.vrm`，或拖入自己的 VRM；无需重新下载模型。
- 数字人启动日志在 `.runtime/digital-human.log`、`.runtime/digital-human-error.log`。3000 被其他服务占用时启动器报错，不终止该服务。
- Android 经 USB 转发 8000/3000 使用电脑服务；网页界面变更不会自动更新已经安装的 APK，完整更新需重新构建安装。
