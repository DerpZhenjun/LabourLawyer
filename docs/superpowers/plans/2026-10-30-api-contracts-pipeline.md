# 稳定接口、统一校验与三端构建

1. 先记录旧请求、响应与用户既有修改；以测试复现缺少 OpenAPI 类型生成、地区校验不一致和旧同步脚本失效。
2. 六个稳定接口路径：health、AI状态/问答、省级目录及两类生成。响应模型与请求约束由实际 FastAPI/Pydantic 导出；导出不启动应用、不初始化生产库、不访问模型。动态地区表单继续走原模板契约，不套用静态生成类型。
3. 用锁定 OpenAPI TypeScript 生成器生成可重复类型与后端约束常量；网页、小程序、数字人引用同一份输出；自动检测 schema/产物漂移。
4. 收拢区县上下文、来源/版本/唯一模板及填写数据校验，保留适配器模型、既有无契约请求、错误状态和文书行为。
5. 统一 check/build/plan/artifact 入口和真实构建回执；整理脚本目录说明，修复旧同步入口；不移动历史采集证据。
6. 运行针对性与全量后端、三端契约、严格编译、实际网页和可用微信模拟器。对比包内资源；运行代码变化时重建并验证安装包、发布新预览版，不改旧标签。
7. 精确白名单分批提交 GitHub，保存实际发布与未验收范围。所有模型调用禁用，Windows 模型不启动。
