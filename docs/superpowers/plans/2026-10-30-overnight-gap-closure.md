# 夜间缺口补齐 Implementation Plan

**Goal:** 在既有可运行预览版上继续补齐真实地区、Linux执行器、数字人部署及交付验证，受外部条件限制的项如实保留。

**Architecture:** 保持网页/小程序共享契约和Python自身模板适配；Linux浏览器执行器与数字人服务使用应用独占用户目录和端口，不改写只读发行。先隔离候选、真实生成/浏览器/Word检查，再增量发布。三条独立实施由并行子任务负责，主任务负责共享集成、证书/客户端、发布与恢复。

**Tech Stack:** FastAPI/Pydantic/SQLite、Vue/TypeScript、Playwright、Next/React/VRM、Capacitor/Gradle、Electron。

- 源码0e8eb56a；preview.3六个发行文件已匿名校验。
