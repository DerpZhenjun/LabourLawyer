# 全国逐地核验续作计划

> **For agentic workers:** 使用 executing-plans 继续现有接入流程；按 dispatching-parallel-agents 将独立省份分组，根线程负责共享代码与合并。

**目标：** 按每个市、区县、功能区自身官方来源持续核验、适配填写生成；不把未核验或搜索未命中解释为官方未提供。

**架构：** 保留精确地区指南库、模板适配器和发布门槛。新增独立公开核验登记及校验器，让采集进展直接出现在管理页面；登记不赋予指南发布或生成能力。省份采集使用独立浏览器会话和文件目录，汇总前逐份审查。

**技术：** Python、现有SQLite公开库、Vue3、Agent Browser、Chrome DevTools MCP、DOCX。

**约束：** 不触碰个人案件库；不覆盖封存原件；不调用模型；不启动Windows Ollama；不绕过既有候选验收站启动限制；不借主站发布候选；所有提交明确文件路径与用途。没有人工明确的官网声明时，仅可标注“已查来源未找到”，不能宣称“官方未提供”。

- [ ] 江苏、浙江、安徽各自核验尚未完成地区，保存真实来源与附件；四川继续核对遗留区县。
- [ ] 为核验状态、官方明确未提供的证据要求、地区绑定和候选登记优先级编写失败测试。
- [ ] 实现独立核验登记校验与网页状态，避免混淆来源缺失、未找到、尚未核验；不扩大生成授权。
- [ ] 根据各地自己模板增加严格适配、虚构生成和逐页检查；现有适配可复用实现，但来源、SHA与适用范围必须逐地绑定。
