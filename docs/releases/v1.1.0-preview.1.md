# LabourLawyer 1.1.0-preview.1

首次软件预览发布：Android USB联调客户端和Windows桌面客户端。供已有电脑后端的开发与试用环境使用；不包含Python后端、官方附件库、个人案件数据库或AI模型，不能仅安装客户端就离线生成文书。

## 本版内容

- 当前劳动仲裁群众服务界面、地区选择、已核验地区文书填写和生成入口。
- AI法律顾问与法律数字人共用Ubuntu Ollama `qwen3.8:27b`，Windows不启动模型。
- 连接状态、重试及流式回答修复；统一品牌图形。
- 当前公共发行数据为181个指南、166个可生成地区。其他候选仍须自己的来源、原件与填写/版式/网页验收；地区目录和省份入口不代表全国已完成。

## Android USB联调包

`LabourLawyer-1.1.0-preview.1-android-usb.apk`，Android 7.0/API24及以上；使用Android调试签名、versionCode 2，保留USB调试能力。这是明确标记的预览包，不是应用商店生产签名版。

1. 在电脑下载本仓库源码，依项目README配置依赖，运行`start.bat web`。
2. 手机允许USB调试、连接电脑。执行`adb reverse tcp:8000 tcp:8000`和`adb reverse tcp:3000 tcp:3000`。
3. 安装APK并打开LabourLawyer。已有相同签名版本可用`adb install -r`覆盖升级，不需要卸载。
4. 保持USB和电脑服务运行。AI需要电脑后端已有可用的Ubuntu远程连接；不需要在手机或Windows安装大模型。

本轮已实际覆盖安装、检查新版本并查看手机首页。手机系统拒绝ADB模拟点击，调试接口检查亦受执行限制，未把原生文书分享、麦克风和数字人交互标为手机端已验收。

## Windows桌面客户端

提供安装版与便携版。先启动源码项目的后端8000；可选数字人服务在3000。客户端启动页会显示依赖并检查后端连接；它不自动安装或启动后端和模型。安装版为当前用户安装，便携版可直接运行。

本预览没有Windows代码签名。桌面包采用自身回环服务代理到固定本机后端，保留流式回答并避免随机端口跨源失败；未关闭浏览器安全隔离。

## 校验与数据保护

下载后对照同一Release的`SHA256SUMS.txt`校验制品。应用不保证文书被仲裁机构受理，也不代交真实申请。不要把身份证材料或已有案件上传为测试数据。
