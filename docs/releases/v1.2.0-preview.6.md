# LabourLawyer 1.2.0-preview.6

本版更新 Android、Windows、小程序导入包、Ubuntu 服务端包和法律数字人源码。Android 版本号为 9，构建源码固定为 `9978ba563c49b84bc1357d640aa404f8ecc6a398`。后续源码提交与本版安装包分别记录，不把更新后的仓库内容倒算进已冻结的软件。

发行快照包含 219 份当地指南、202 地填写生成和 3,974 条地区目录。目录包含省市层级，不能当作全国区县覆盖数；全国接入尚未完成。新增平潭使用自身官方事项和空白申请书、证据清单；样表与未适配附件保留区别。各地受理要求、机构、材料份数和网上办理情况仍以页面的来源及核验状态为准。

## 下载与使用

- `android.apk`：保留 `cn.labourlawyer.mobile` 包名及原调试证书，用于兼容旧预览版升级。不要为安装而卸载旧应用。
- `android-independent-signed.apk`：包名为 `cn.labourlawyer.mobile.release`，复用已有持久签名，关闭应用及 WebView 调试。可与兼容版并存，数据和连接设置不自动互通。
- `windows-x64-setup.exe` / `windows-x64-portable.exe`：Windows x64 安装版和便携版。尚无可信 Windows 发布者签名。
- `ubuntu.tar.gz`：网页、API、公开指南和已核验原件部署包。仅为空公共库初始化快照；已有指南库不会自动合并覆盖。部署与增量数据更新须单独验收，不包含私人案件库、登录会话或模型。
- `miniprogram.zip`：可导入微信开发者工具的工程和已编译业务代码。未上传或发布到微信，需要实际 AppID、开发权限和可达后端。
- `digital-source.tar.gz`：同一冻结源码的数字人源包，含文件校验清单和 Next.js 15.5.28 锁文件。按包内 `ChatVRM/deploy/README.md` 配置；不包含或启动模型。
- `START-HERE.txt` / `SHA256SUMS.txt`：使用说明及其余八个文件的校验值。先核对校验值，再安装或部署。

客户端需要后端。在“连接设置”填写已部署服务的地址：Windows 默认的 `http://127.0.0.1:8000` 仅指当前电脑；手机应连接同一可信网络内可访问的后端。安装客户端不会启动后端或 Windows 模型。AI 使用已配置的 Ubuntu Qwen3.8，连接失败不影响本地填写和后端文书生成。

## 验收范围与限制

冻结源码的 GitHub 检查通过 418 项后端测试、2 项独立故障回归及网页、小程序构建。四端安装包另行从相同源码构建，检查实际包内网页、版本、签名和文件字节；本版 Android 独立证书保持不变。

构建期间保留了两次未通过的记录：依赖目录连接导致 Capacitor 写入旧路径，以及首次同步新增配置触发源码一致性检查。合格构建使用实体 Android 依赖并核对首次同步产物；受版本控制的 6,526 个源码文件保持相同。后续仓库已继续修复构建流程，不能据此宣称本版源码包含尚未进入冻结版本的改动。

本机和 Ubuntu 运行站已按独立增量步骤达到 219/202；平潭两站共八次正式网页下载通过来源、契约、整包和全部 ZIP 成员核对。运行站仍有各自独立的数据历史，不能以发行包覆盖现有用户数据。旧 preview.5 和 server-preview.1 附件及标签保持不变。

USB 检查未发现授权设备，本版不声明实体手机安装或运行通过。公开域名与可信 HTTPS、可信 Windows 代码签名及微信发布尚未完成。OpenClaw 的真实回执、待投递问题与指南核验分开统计；回执不代表 AI 审查或官方受理。本项目仍为辅助工具预览版，文书生成不保证被受理。
