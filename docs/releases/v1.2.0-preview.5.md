# LabourLawyer 1.2.0-preview.5

这是一版可下载的预览软件，全国市、区县尚未完成接入。地区目录、已采集指南、可以填写生成的模板分别统计；未核验不表示官方没有提供。

## 下载与使用

| 文件 | 用途 |
|---|---|
| `android.apk` | 保留原包名、原调试签名的兼容升级版 |
| `android-independent-signed.apk` | 复用持久签名的独立包，可与兼容版并存；关闭应用和 WebView 调试 |
| `windows-x64-setup.exe` | Windows 安装版 |
| `windows-x64-portable.exe` | Windows 便携版 |
| `ubuntu.tar.gz` | 网页、API、已核验公开原件及部署说明，不含私人数据库、账号或模型 |
| `miniprogram.zip` | 可导入微信开发者工具的本地工程，尚未上传或发布到微信 |
| `digital-source.tar.gz` | 独立数字人源码及文件校验清单，不含 Ollama 模型 |
| `START-HERE.txt` | 各端连接及使用说明 |
| `SHA256SUMS.txt` | 前八个文件的 SHA256 校验值 |

Android 版本号为 8。两个 Android 包的数据、登录状态和连接地址不会自动互通；不要为了升级而卸载旧应用。Windows 软件目前没有可信代码签名。

客户端需要连接已启动的后端。进入“连接设置”填写可信服务地址，检查后保存；Windows 重新打开软件后保留该地址。Ubuntu 部署包可在空公共库引导 **209 份地区指南、192 地填写生成、3,974 条地区目录**，已有数据库不会自动合并或覆盖。该数字是发行快照，不代表全国完成，也不代表所有指南栏目均已核实。

公网部署仍需要域名与可信 HTTPS；局域网 HTTP 仅供可信网络预览。安装客户端不会自动启动后端或模型。AI 使用 Ubuntu 的 Qwen3.8，Windows 不运行本机模型。

## 本次改进

- 公共省份文书草稿按服务地址、登录账号、地区和文书类型隔离，匿名设备草稿单独保存。退出登录、切换账号会清理当前页面中的旧身份内容，并取消过期的生成操作。
- 保留旧版本设备草稿，不自动迁入登录账号。“重置本次填写”只重置当前范围，不承诺擦除所有历史设备数据。
- 增加独立采集问题日志、持久 outbox、管理员投递状态和经过真实 OpenClaw 回读才能确认的同步工具。部署了工具不等于问题已经送达，具体数量以运行站实际回执为准；服务确认也不等于 AI 审核。
- 台江、仓山分别按本区官方资料接入申请书和证据清单，保留各自材料份数。未核实的完整委员会名称、签名和日期留空；示例样表不当作空白模板。
- 后端生成文书存放于持久数据目录，下载结束清理本次临时文件，避免写入不可变部署源码目录。

隔离测试账号的真实登录、退出、匿名/甲/乙草稿隔离、重新登录恢复及仅重置本人草稿均通过；没有访问生产账号或案件。[本批地区上线验收](https://github.com/DerpZhenjun/LabourLawyer/blob/main/reports/overnight-gap-closure-20261030/localities/fujian-i/rollout-20261031/DEPLOYMENT-ACCEPTANCE.json)。
