## Android USB预览包

`LabourLawyer-1.1.0-preview.2-android-usb.apk`，Android 7.0/API24及以上，调试签名，versionCode 3。相同签名的旧版可直接覆盖安装，保留应用数据。

1. 在电脑按仓库README配置依赖，运行`start.bat web`，另行启动数字人服务3000。
2. 手机连接USB、允许调试。执行`adb reverse tcp:8000 tcp:8000`及`adb reverse tcp:3000 tcp:3000`。
3. 执行`adb install -r LabourLawyer-1.1.0-preview.2-android-usb.apk`，打开应用。

保持USB与电脑服务运行。AI继续通过项目后端连接Ubuntu Ollama `qwen3.8:27b`；手机和Windows都不安装或启动模型。
