## 下载与启动

本 Release 提供 Android APK、Windows x64 安装版和便携版，以及使用说明、SHA256SUMS。

这些包包含界面，**不包含 Python 后端、官方模板库、用户案件库或模型，不能单独离线生成文书**。先下载源码、配置依赖，在项目根执行 `start.bat web`，保持后端运行于 `127.0.0.1:8000`。法律数字人另需本项目 3000 服务；AI 使用已配置的 Ubuntu Ollama / qwen3.8:27b，不在 Windows 启动模型。

Windows 双击 setup 安装版或 portable 便携版。两者均为尚未代码签名的预览包。本轮运行并验收的是同批打包的程序，未执行安装向导。

Android 要求 API 24 / Android 7.0 及以上，versionCode 5，与旧预览版使用同一调试证书，可覆盖安装：

```powershell
adb reverse tcp:8000 tcp:8000
adb reverse tcp:3000 tcp:3000
adb install -r LabourLawyer-1.2.0-preview.2-android-usb.apk
```

本轮 USB 列表为空，未进行手机覆盖安装或原生分享验收。APK 的签名、版本、ZIP CRC 及 83 份网页资源逐字节对照通过。请用本页 SHA256SUMS 核对下载文件。
