# LabourLawyer 1.2.0-preview.1 · Android

本版将群众入口、区县指南、文书填写及管理页面继续迁入 TypeScript。34 个 Vue 文件的脚本均使用 TypeScript，并启用完整严格类型与模板检查；兼容 JavaScript 入口保留。

## 更新

- 网页、微信小程序和法律数字人代理复用 AI 请求与远程状态契约，保留 Ubuntu Ollama / qwen3.8:27b 配置，不启动 Windows 本机模型。
- 区县原件下载同时绑定来源和版本，过期链接要求重新核对。各地模板、材料和覆盖数量保持不变。
- 历史省级 34 类填写请求与迁移前逐项一致。坏草稿不会被自动覆盖；浏览器存储不可用时仍可生成。
- 修复清空聊天后旧流式回答回填、刷新迟到响应覆盖新状态及小程序把 HTTP 错误正文当回答等边界。

## Android 安装与使用

下载 `LabourLawyer-1.2.0-preview.1-android-usb.apk`，Android 7.0 / API 24 及以上。调试签名，versionCode 4；证书与上一预览版相同，可以覆盖安装，无须卸载旧应用。

1. 先在电脑配置本仓库依赖并启动网页/后端：`start.bat web`。数字人另需本项目的 3000 服务。
2. 手机通过 USB 连接电脑并允许调试，执行：

```powershell
adb reverse tcp:8000 tcp:8000
adb reverse tcp:3000 tcp:3000
adb install -r LabourLawyer-1.2.0-preview.1-android-usb.apk
```

3. 打开应用，在省、市、区县选择后填写并生成。使用同页 `SHA256SUMS.txt` 核对安装包。

这是需要电脑后端和 USB 转发的预览包，**不能安装后离线生成文书**。包内不含 Python 后端、官方模板库、个人案件库、数字人服务或 AI 模型。AI 不可用时仍可填写、生成文书。
