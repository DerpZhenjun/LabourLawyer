# LabourLawyer 1.2.0-preview.4

本预览版接入常熟、张家港各自的申请书和证据清单，新增持久 Linux 公开指南采集后台，并将独立 Ubuntu 数字人接入客户端的服务发现。公共文书填写继续免登录，案件与管理功能保留账号隔离。

## 下载选择

- `android.apk`：原包名 `cn.labourlawyer.mobile`、原调试证书，供已有预览用户兼容更新，不需要卸载旧应用。
- `android-independent-signed.apk`：独立包名 `cn.labourlawyer.mobile.release`，使用持久应用签名，关闭 Android 与 WebView 调试。与旧应用并排安装，数据和连接配置不自动迁移，不代表商店上架。
- `windows-x64-setup.exe` / `windows-x64-portable.exe`：Windows 安装版或便携版，尚无可信代码签名。服务地址保存在应用自身配置，完全重启后仍保留。
- `ubuntu.tar.gz`：网页、API、公开指南与官方原件部署包，不含私人数据库、会话或模型；首次启动只向空公共库导入快照，已有数据库不会覆盖。
- `digital-source.tar.gz`：独立数字人源码与文件校验清单。按包内 `ChatVRM/deploy/README.md` 部署，复用既有 API，不安装或启动 Ollama。
- `miniprogram.zip`：小程序本地导入工程，保留既有 AppID 和编译后的业务脚本。需要微信开发者工具及合适的开发权限、后端地址，未上传或发布到微信。
- `START-HERE.txt` / `SHA256SUMS.txt`：安装边界与逐项文件校验。

客户端不包含后端、用户资料或模型。先部署服务，再在客户端“连接设置”填写可信服务地址。局域网 HTTP 仅供可信网络预览；公开托管仍需域名与可信 HTTPS。

## 本轮变化

常熟与张家港分别绑定自身来源、模板 ID、版本和 SHA256；官方样表不会当空白模板使用。填写默认内容为虚构示例，证据从一项开始；生成前确认或取消，签名留空，不代交申请。两地共四类文书通过候选网页真实下载及下载件逐页检查。发行快照为 **205 份当地指南、188 个可填写生成地区**；全国仍未完成，未核验不等于官方未提供。

数字人使用上半身客服小窗。客户端先读取所选后端的数字人地址；显式保存的数字人地址仍优先。修复窄屏裁切和 iframe 内 Esc 无法关闭的问题。Ubuntu 独立服务已实际运行并完成合成问答；Windows 不启动本机模型，文书生成不依赖模型。

新增 `/admin/collector` 与管理员 API，使用独立 Linux 浏览器、持久任务库、单 worker 锁、有限重试与独立尝试证据。官方地址与明确地区必须手动指定。实际页面观察、认证边界、附件下载失败如实保留，观察不会自动变成地区指南或模板适用结论。

Windows 原公开问题库的 377 条 OpenClaw 回执保留。新增采集器的两条公开问题通过独立投递库取得真实服务回读确认，AI 分析仍为 0；没有复制私人配置或把文件导出冒充已同步。持续自动投递尚未完成。

## 明确未完成

全国其他市、区县与功能区仍需逐地核验；部分已发布指南字段仍待确认。没有公网域名或可信公网 HTTPS；TLS 工具仅完成显式信任测试 CA 的本地验收，没有修改系统信任。Windows 安装包未代码签名，微信未发布，本轮未发现可安装的 USB 手机，不声明真机安装成功。安装包和局域网验收均不代表商业上线完成，也不保证仲裁机构受理。
