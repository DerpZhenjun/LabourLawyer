# LabourLawyer 1.2.0-preview.3

本预览版增加账号与案件隔离、可配置服务连接、Ubuntu局域网部署包，以及淳安县自身官方文书填写。公共文书填写继续免登录。

- 管理入口使用独立账号，没有默认密码；案件、日程和金额汇总按账号隔离。历史案件保留，需维护人员明确认领，不自动交给新账号。
- 登录状态只在当前标签页保存；退出、过期或切换账号清除私人界面。旧浏览器草稿保留，不自动上传。对话不会自动沿用其他服务或账号的历史。
- 连接设置可填写可信的Ubuntu服务，手机无需一直使用USB转发。局域网HTTP只用于可信网络预览，公网需另行配置HTTPS。
- 淳安县申请书仅填写劳动者部分，证据清单使用淳安县自身原件。真实网页生成及下载件逐页Word检查通过，签名仍须本人核对、手写。
- Windows项目公开问题已通过隔离OpenClaw服务逐条核验377项并保存回执，AI分析数为0。Ubuntu安装包不含该Windows私有OpenClaw配置、账号或回执库。
- AI仅连接已核验的Ubuntu24.04 Qwen3.8:27b；安装包不含模型，不启动Windows模型。

## 下载与使用

Android APK、Windows安装版和便携版均为预览客户端；Ubuntu tar.gz另含后端、网页及经核对的公开指南和原件。先按源码中的 `docs/ubuntu-deployment.md` 配置服务器，再在客户端连接设置中填写地址；默认本机后端仍为 `http://127.0.0.1:8000`。

下载后逐文件对照同页 `SHA256SUMS.txt`。Android为调试签名，Windows尚未代码签名，不代表正式商店上架。数字人服务仍需单独部署，未包含在Ubuntu网页/API包中。微信小程序未上传发布。

全国区县尚未完成。地区目录不等于官方指南覆盖；未核验不等于官方没有提供。当地官方最新要求及实际受理判断优先。
