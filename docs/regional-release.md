# 地区数据接入与公共发行

版本以 `data/public-regions/manifest.json` 为准。2026-10-28 版本包含 181 个已发布指南、166 个可填写生成地区；目录不是指南覆盖，候选不是上线地区。

## 初始化

运行 `python scripts/bootstrap-public-data.py` 或启动后端，仅向空的公共指南、目录库导入发行快照；已有库不合并、不清空、不覆盖，不操作案件或用户库。摘要不一致时停止。附件缺失或身份不匹配时关闭对应生成。

## 接入流程

1. 浏览本地区官方事项，保留来源、机关、编码、地区、时间和栏目原文。
2. 检查材料，区分空白、样例和说明；每份附件保留下载地址、原名、SHA-256 和适用范围。
3. 核实办理方式。网上指南不等于网上提交，登录后的流程未知时保持待核验。
4. 独立测试库接入、编写精确来源约束，不能只凭相同文件字节适配另一个地区。
5. 生成虚构文书并逐页核对，再真实浏览器验收选址、填写、确认/取消、下载、来源与响应式。
6. 通过后备份公共库、增量发布，执行 `python scripts/export-public-data.py` 更新快照并审查差异。

本轮滨海县、响水县各采集四项材料和八个附件；上城区四项材料、两个空白文书；滨江区材料与流程冲突。四地均未完成候选网页验收，不计入发布数。此前验收站启动被执行策略拒绝，未换端口或方式绕过。

## 证据与测试

公开固定证据保留原始字节，`.gitattributes` 防止换行转换破坏 SHA。部分封存集包含官方登录跳转或响应 Cookie，不作为公共 fixture 分发；缺少完整集的相关测试明确 skip，本地完整集仍运行。不能重算封存摘要来伪造通过。

README 图片由实际网页拍摄，是产品展示；正式浏览器与文书验收仍需单独执行、留证。

## 问题记录

搜索失败、同义词重试、事项误匹配、材料缺失、登录/验证码边界、下载失败和来源冲突，应记录地区、事项、URL、时间、原因、尝试和最终状态。OpenClaw 不可用时持久化 outbox 为 `PENDING_OPENCLAW`，真实接收确认后才更新。

不采集登录后私人资料，不绕过验证码，不代交申请，不上传身份信息或文书正文。工具受限时保存证据，继续其他独立地区，不能据此判断官网故障。
